SMART GROCERY STORE MANAGEMENT SYSTEM

Files:
- grocery_store.py: Main Python application
- README.txt: Instructions

How to run:
1. Extract this ZIP file.
2. Open the folder in VS Code or another Python editor.
3. Open a terminal in the folder.
4. Run: python grocery_store.py

The program includes product management, search, stock updates, sales,
sales records, and a store report. Data is currently held in memory and
resets when the program exits.
